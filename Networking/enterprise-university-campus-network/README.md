# Enterprise University Campus Network Design

This project demonstrates the design and implementation of a multi-campus university enterprise network using Cisco Packet Tracer.

## Key Features
- Multi-building main campus and branch campus connectivity
- VLAN-based departmental segmentation
- Inter-VLAN routing using Layer 3 switches
- RIPv2 for internal routing
- Static routing to external cloud email server
- Router-based DHCP configuration
- Internal Web and FTP servers

## Technologies Used
- Cisco Packet Tracer
- VLANs
- RIPv2 Routing
- Static Routing
- DHCP
- IP Subnetting
